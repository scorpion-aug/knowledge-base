## Quick install
`curl -fsSL https://get.activepieces.com | sh` — then follow Self host (Docker): opening Activepieces, activating a license key, upgrading, fixing problems.

## All options
- **Self-host Activepieces (recommended):** Docker Compose with PostgreSQL and Redis.
- **Run on Kubernetes:** Helm chart ("only if you already run a cluster").
- **Activepieces Cloud (fastest):** hosted and managed by Activepieces, start free.

## Other ways to deploy (community-maintained; install the free Community edition; versions can lag)
- AWS (Pulumi), GCP (VM template), Railway, Elestio, Easypanel, PikaPods (from $2.9/month), RepoCloud, Zeabur.
