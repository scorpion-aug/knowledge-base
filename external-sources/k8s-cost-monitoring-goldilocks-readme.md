> Text of the master README (trimmed of badges/logo) plus facts from https://github.com/FairwindsOps/goldilocks (License: Apache-2.0, 454 commits, created 2019-04-25) and https://github.com/FairwindsOps/goldilocks/tags.

Goldilocks helps identify a starting point for resource requests and limits. It creates a Kubernetes Vertical Pod Autoscaler (VPA) in recommendation mode for each workload in a namespace and shows the recommendations in a dashboard. Docs at goldilocks.docs.fairwinds.com. Images moved from quay.io to us-docker.pkg.dev/fairwinds-ops/oss/goldilocks starting v4.15.0; images are signed and tags immutable. Multi-cluster, history and integrations are pushed to the commercial Fairwinds Insights.
