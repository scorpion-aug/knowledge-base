# The AI-Native SDLC Playbook (Coursera course page)

Instructor: Anthropic Academy. 8 modules, beginner level, ~2 hours. Recently updated: October 2026. Free (no certificate).

## Course description (verbatim)

For engineering, platform, and security leads whose organization already uses Claude Code. Twelve plays for using Claude at each stage of the software development lifecycle (SDLC), so the work around the code runs faster.

When agents write the code, building stops being the bottleneck. The planning, review, and deployment stages around it start to stall instead. This playbook shows how to run those stages at the new speed while human judgment and enterprise controls stay in place.

The plays follow the lifecycle from plan to maintain:

- Plan and design with reviewed intent.md and spec.md files committed to version control
- Build from Claude Code plan mode, a lean CLAUDE.md, skills that carry team conventions, and parallel sessions with subagents
- Test with a single-command target Claude can run itself and an eval suite built from real tasks in CI
- Deploy behind a REVIEW.md, approval hooks, and non-interactive pipeline jobs
- Maintain with deterministic control bands that call Claude in tiers when a metric drifts

The practices come from Anthropic's Applied AI team and its work with enterprise customers, with governance and regulatory requirements in mind throughout.
